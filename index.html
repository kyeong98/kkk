구간 반복 · 체크 장면 이동 · OCR · 문장 편집 · 단어장

1. 영상 선택 및 시간 체크

유튜브가 재생되지 않으면 아래 ‘테스트 모드’를 사용하세요.
현재 시간: 00:00영상 미선택
0 = 무한 반복
시작/종료 지점을 지정하세요.

참고: 유튜브 임베드가 차단되는 영상도 있습니다. 테스트 모드에서는 영상 없이 시간 기록 기능을 시험할 수 있습니다.

2. 자막/스크립트

기존 스크립트가 있으면 붙여 넣으세요. 문장을 나누고 단어로 분석합니다. 번체·간체 모두 됩니다.

중국어 문장을 입력한 뒤 단어 나누기를 누르세요. 병음·뜻은 직접 고치거나 AI로 채울 수 있습니다.

3. 이미지 자막 OCR

스크린샷을 선택해 글자를 인식합니다. 첫 실행에는 인터넷이 필요할 수 있습니다.

선택한 위치의 글자 중 중국어 줄만 남깁니다. 휴대폰 스크린샷처럼 영상이 화면 일부만 차지하면 '화면 전체'를 고르거나 영상 부분만 잘라서 올리세요. PC에서는 스크린샷 후 Ctrl+V로 바로 붙여넣을 수 있습니다.

이미지를 선택하세요.
자막을 추출하면 AI가 공부할 단어를 추천합니다.

4. 음성 구간 / 음성 인식 텍스트

현재는 음성 구간의 시작·끝 시간을 기록하고, 다른 곳에서 받아 적은 STT 결과를 붙여 넣어 수정하는 기능입니다. 유튜브 음성을 앱이 직접 듣고 자동 변환하는 기능은 아직 연결되지 않았습니다.
